# 🌳 JSON Tree Visualizer

> **Visualize • Explore • Search JSON with ease**

A lightweight and interactive tool that converts raw JSON into a clean, expandable tree structure, making complex and deeply nested JSON easy to understand and explore.

---

## ✨ Features

- 🔹 Visualize JSON data in a **tree format**
- 🔹 Expand and collapse each child node
- 🔹 Search for a **specific key or node** instantly
- 🔹 Supports **deeply nested objects and arrays**
- 🔹 Clean, minimal, and developer-friendly UI

---

## 🚀 What This Project Does

This project allows users to:

1. Paste or input any valid JSON
2. Convert it into a structured tree view
3. Expand each level to explore child nodes
4. Search and highlight a particular node in the tree

Perfect for debugging API responses, learning JSON structures, or inspecting large datasets.

---

## 🔍 Search Functionality

- Search by **node/key name**
- Automatically expands the tree to reveal matches
- Highlights the searched node for better visibility
